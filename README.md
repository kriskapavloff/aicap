# AICAP — детектор признаков ИИ-генерации в визуальных данных

Проект переработки системы AICAP из дипломной работы «Макет модуля обнаружения признаков
искусственного интеллекта в визуальных данных в сфере образования» (РТУ МИРЭА, 2026).

В дипломе система была спроектирована архитектурно (метод ARCADIA/Capella) и обоснован
выбор методов детекции, но код не был реализован и не запускался. Этот репозиторий —
реальная реализация, оценка на данных и честный разбор того, где метод работает и где ломается.

## Статус

Проект в разработке. Модули добавляются по одному, с тестами на реальных данных.

## Архитектура

- `fft_detector.py` — частотный анализ (радиальный профиль спектра мощности)
- `preprocessing.py` — валидация и подготовка изображений
- `exif_detector.py` — анализ метаданных EXIF
- `cnn_detector.py` — нейросетевой детектор на базе CLIP (подход UnivFD)
- `gradcam.py` — визуализация зон, повлиявших на решение модели
- `aggregator.py` — агрегация оценок отдельных детекторов
- `experiments/` — прогон на датасете, метрики, тесты на устойчивость

## Запуск

```bash
python -m venv venv
venv\Scripts\activate        # Windows
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
```

`torch`/`torchvision` ставятся отдельной командой с CPU-сборкой (флаг `--index-url`) —
без него pip по умолчанию притянет версию с поддержкой CUDA, которая весит на порядок
больше и для этого проекта не нужна (весь пайплайн рассчитан на CPU).

Запуск отдельных детекторов:

```bash
python -m aicap.fft_detector путь/к/картинке.jpg
python -m aicap.exif_detector путь/к/картинке.jpg
python -m aicap.preprocessing путь/к/картинке.jpg
```

(инструкции по запуску будут дополняться по мере готовности остальных модулей)
